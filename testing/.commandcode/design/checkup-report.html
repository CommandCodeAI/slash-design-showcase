// PRIORITY ISSUES
P0

Mobile navigation missing

Nav links (Product, Developers, Docs, Security, Pricing) are hidden lg:flex — completely inaccessible below 1024px. No hamburger menu, no disclosure button, no alternative path. On mobile, the user sees only the logo and "Get access" button. This blocks wayfinding for the majority of mobile visitors.

FIX: Add a mobile menu toggle that reveals nav links on small screens. All destinations must be reachable at 320px.
P1

Focus states undefined

No focus-visible or focus styles anywhere. Keyboard users get only the browser default outline, which on dark backgrounds may be invisible or inconsistent. Links and buttons are focusable but the focus ring is not designed.

FIX: Add focus-visible styles to all interactive elements — 2-3px ring with offset, 3:1 contrast against background.
P2

Tailwind CDN render-blocking

Tailwind loaded via CDN script, causing flash of unstyled content and render delay. The ~400KB script compiles classes in the browser, delaying first meaningful paint.

FIX: For production, use a precompiled Tailwind build. For a demo, accept the tradeoff but be aware.
