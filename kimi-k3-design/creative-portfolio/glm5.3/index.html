About

I design and build expressive web experiences — where typography, motion and engineering carry equal weight, and detail is the whole point.

I'm Milo — a frontend developer and designer who has spent eight years making the web feel less templated. I've shipped work for type foundries, festivals and founders across Europe, usually living somewhere between the design file and the render loop.

The best compliment my work gets is that it feels expensive. The second best: "wait, this is a website?" Both usually come down to the same things — typography, timing, and caring about the last four pixels.
