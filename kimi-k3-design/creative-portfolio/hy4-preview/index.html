    A tiling engine that never repeats

    A WebGL wallpaper generator for a Rotterdam print studio. Sixteen thousand tiles per frame, zero visible repetition, exported at press resolution.

    Frame time

    How it works

04Approach

Four moves,
in this order.

  1. 01

    Name the job

    Before a layout exists I write one sentence about what the screen is for. If I cannot, the section does not get built yet.

  2. 02

    Structure first

    Real headings, real landmarks, real labels, no styling. Keyboard complete before a single color is chosen.

  3. 03

    Build every state

    Empty, loading, error, overflow, disabled. A screen that only works with good data is a sketch, not a build.

  4. 04

    Earn the motion

    Animation only survives if it explains a state change. Anything decorative gets cut in the last pass, and I usually cut half of what I wrote.
